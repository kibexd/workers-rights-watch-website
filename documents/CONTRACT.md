## 1.1 PROJECT BACKGROUND & MIGRATION CONTEXT

**Original Website:**
- Platform: WordPress with PHP
- Hosting: cPanel (Kenya Website for Logistics)
- Status: Live at www.workersrightswatch.org

**Redesign & Migration:**
- New Platform: Next.js 15 (modern, fast, enterprise-grade framework)
- New Hosting: Vercel (optimized for Next.js applications)
- Migration Reason: The previous WordPress site was difficult to maintain and update. Direct database edits via phpMyAdmin did not reflect changes on the live site due to caching and plugin conflicts. The redesign offers better performance, security, and maintainability.
- Domain: www.workersrightswatch.org will remain the same; only DNS configuration will change to point to Vercel
- Old Site Backup: Previous WordPress site will be preserved as backup during transition

**Credentials:**
- Previous Credentials (WordPress/cPanel): Already with Client
- New Credentials (Vercel/GitHub): Will be provided by Developer upon deployment
