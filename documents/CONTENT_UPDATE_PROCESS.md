## TYPES OF UPDATES & WHAT TO PROVIDE

### 1. NEW EVENT/ACTIVITY

**Information Needed:**
- Event title
- Event date
- Event description (2-3 paragraphs)
- Event photos (3-10 high-quality images)
- Event location
- Number of participants (if applicable)

**Example Request:**
```
Type: New Event
Page: Activities Page
Title: "Workers' Rights Training Workshop - Kiambu"
Date: December 5, 2025
Description: [Provide full text]
Attachments: 5 photos from the event
```

---

### 2. NEW TEAM MEMBER / STAFF UPDATE

**Information Needed:**
- Full name
- Job title/position
- Bio (2-3 paragraphs)
- Professional photo (high-quality headshot)
- Email (if to be displayed)

**Example Request:**
```
Type: Add New Staff Member
Page: Our Team Page
Name: John Doe
Position: Finance Officer
Bio: [Provide full text]
Photo: Attached
```

---

### 3. REMOVE/UPDATE EXISTING STAFF

**Information Needed:**
- Staff member name
- Action: Remove or Update
- If updating: new information and/or photo

**Example Request:**
```

Page: Our Team Page
Name: Caroline Nyambura
Action: Remove from website
Reason: No longer with organization
```

## FILE SUBMISSION GUIDELINES

### Images/Photos

**Format:** JPG or PNG
**Size:** Minimum 1200px width for main images
**Quality:** High resolution (avoid blurry/pixelated images)
**File Size:** Under 5MB per image (compress if larger)

### Documents/PDFs

**Format:** PDF only
**Size:** Under 10MB (compress if larger)
**Quality:** Ensure text is readable and not scanned at low quality

### Videos (If Applicable)

**Format:** MP4, YouTube link, or Vimeo link
**Size:** Under 50MB if uploading directly
**Preferred:** Upload to YouTube/Vimeo and provide link

## APPROVAL PROCESS

1. **Request Submitted** → Developer receives and acknowledges
2. **Estimated Time** → Developer provides completion timeline
3. **Development** → Developer implements changes on staging/preview
4. **Review** → Client reviews changes via preview link
5. **Approval** → Client approves or requests adjustments
6. **Deployment** → Changes go live on main website

Each month, the developer will provide a summary:

**Updates Completed:**
- List of all updates made
- Hours used (out of 2 hours included)
- Additional hours (if any)

**Remaining Time:**
- Hours remaining for the month
- Resets on the 1st of each month

---

## TIPS FOR EFFICIENT UPDATE REQUESTS

✅ **DO:**
- Provide complete information in one request
- Attach all necessary files
- Specify exact changes clearly
- Review old content before requesting changes
- Batch multiple small updates into one request

❌ **DON'T:**
- Send incomplete information
- Request updates via multiple channels simultaneously
- Send vague descriptions ("make it look better")
- Submit multiple small requests separately
- Expect instant changes without prior notice
