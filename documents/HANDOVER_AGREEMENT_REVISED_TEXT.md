## 3. TECHNICAL SUPPORT & GUIDANCE

### **Important Technical Requirement:**

Unlike WordPress, **Next.js requires coding knowledge** for all content updates. Content updates cannot be made through a visual dashboard by non-technical staff.

### **Training & Guidance Provided:**

The Developer will provide training and documentation on:

✅ **Monitoring website performance** via Vercel dashboard
✅ **Reviewing contact form submissions** and job applications received through the website
✅ **Requesting content updates** from the Developer (process outlined below)
✅ **Understanding website analytics** and traffic reports
✅ **Accessing and reviewing website backups** via GitHub

### **Content Update Process:**

**CRITICAL:** All content updates (text changes, new pages, PDF uploads, image additions, event updates) must be handled by the Developer or someone with coding knowledge. The Programs Officer can request updates, and the Developer will implement them.

**How to Request Updates:**
1. Send update request via email (kibeenock7390@gmail.com) or WhatsApp (0735663656)
2. Include: specific changes needed, new content/images/PDFs, and any deadlines
3. Developer implements changes within 48 hours (or as per maintenance agreement)
4. Client reviews and approves changes

**Why the Developer Must Remain Involved:**
- Technical requirement of Next.js platform (not optional)
- Ensures professional quality updates
- Prevents security vulnerabilities
- Maintains consistent design and functionality
- Proper testing before changes go live

The Developer must remain in the loop for all technical aspects of the website.
